# Resolutive Prior Art

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22055552.svg)](https://doi.org/10.5281/zenodo.22055552)

Canonical technical specification and defensive prior-art registry for the Resolutive Technology family.

This repository centralizes versioned technical disclosures, specifications, reproducibility evidence, and DOI-linked releases for the Resolutive family of technologies.

## Published baseline

**Resolutive Prior Art Registry v0.1.0** — archived on 2026-08-22.  
DOI: `10.5281/zenodo.22055552`

The v0.1.0 archival release establishes `RF-0001` as the cross-family foundational architecture and freezes the initial registry covering Resolutive Memory, trajectory addressing, MA2A architecture/synchronization/organizational PKI, and related experimental Resolutive technology families.

Claims concerning O(1) resolution, reversibility, compression, performance, and physical models are limited to the specific operations and evidence stated in each disclosure.

> Status: first archival defensive-publication baseline published. New technical material remains versioned and must distinguish hypothesis, experiment, validation, and publication status.
