# Resolutive Prior Art

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22320536.svg)](https://doi.org/10.5281/zenodo.22320536)

Canonical technical specification and defensive prior-art registry for the Resolutive Technology family.

This repository centralizes versioned technical disclosures, specifications, reproducibility evidence, external prior-art surveys, and DOI-linked releases for the Resolutive family of technologies.

## Latest archival release

**Resolutive Prior Art Registry v0.2.0** — archived on 2026-09-05.  
DOI: `10.5281/zenodo.22320536`

Version 0.2.0 extends the first archival baseline with materially strengthened disclosures for:

- `RM-0003 v0.2` — persistent concept identity, restart-safe persistence/materialization and deterministic miss-only native concept resolution;
- `RF-0002 v0.2` — policy-first admissible routing over knowledge availability and heterogeneous compute state;
- `RT-0002 v0.3` — information-event time, macro-event rank/unrank and exact microscopic recurrent-trajectory reconstruction within the documented domain.

The release also freezes the external prior-art survey used to narrow the claims of these mechanisms.

## Historical baseline

**Resolutive Prior Art Registry v0.1.0** — archived on 2026-08-22.  
DOI: `10.5281/zenodo.22055552`

The v0.1.0 release remains the immutable first archival defensive-publication baseline. It established `RF-0001` as the cross-family foundational architecture and froze the initial registry covering Resolutive Memory, trajectory addressing, MA2A architecture/synchronization/organizational PKI, and related experimental Resolutive technology families.

Claims concerning O(1) resolution, reversibility, compression, performance and physical models are limited to the specific operations and evidence stated in each disclosure.
