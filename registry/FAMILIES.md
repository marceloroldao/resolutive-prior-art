# Resolutive Technology Families

This registry groups disclosures by technical family while preserving independent evidence maturity for each entry.

## RM — Resolutive Memory / Memoria.ia

Deterministic memory structures, trajectory-addressed retrieval, state organization, persistence, synchronization primitives, and directly related mechanisms.

## MA2A — Memoria.ia Agent-to-Agent Protocol

Agent discovery, session negotiation, cryptographic identity, state/trajectory synchronization, conflict resolution, privacy boundaries, organizational PKI, and L1/L2/L3 network architecture.

## TRI — TRIVAX

Technical mechanisms and validated properties belonging to the TRIVAX line of work.

## RI — Resolutive Inference

Inference mechanisms, compact models, online adaptation, control-oriented inference, benchmarks, and comparative evidence.

## RC — Resolutive Computing

Computational mechanisms, resolutive search/optimization, numerical procedures, and reproducible performance evidence.

## RT — Resolutive Trajectory

Reversible state machines, trajectory encoding/recovery, state-transition constraints, reconstruction, and information recovery experiments.

## BA — Bit Analysis

Hierarchical bit/byte relation analysis, multilevel relation structures, reconstruction, and corruption-resilience experiments.

## RP — Resolutive Physics

Mathematical models and physical hypotheses. Entries in this namespace must state evidence level especially carefully and must not present exploratory models as experimentally established physics.

## Cross-family disclosures

A disclosure should have one primary namespace. Dependencies on other families are referenced explicitly rather than duplicating the same disclosure under multiple IDs.
