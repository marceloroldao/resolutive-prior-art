## 1. Technical problem

Embedded and battery-powered systems frequently need online decisions from noisy sensor streams under strict limits on compute, memory, and energy. Conventional approaches may rely on neural networks or general-purpose probabilistic models whose runtime or update cost can be disproportionate to the control problem.

RI-0001 discloses a compact resolutive inference architecture designed for low-parameter, online-adaptable decision making on edge devices. The target applications include IoT, robots, drones, and autonomous controllers.

## 2. Definitions

- **Observation:** current sensor/input vector.
- **Resolutive state:** compact internal representation used for inference.
- **Attractor/prototype:** compact representative state associated with a regime or response.
- **Update rule:** deterministic or bounded adaptive rule modifying the compact state from new evidence.
- **Compact model:** inference structure with deliberately limited parameter count and memory footprint.
- **Online learning:** model adaptation during operation without full offline retraining.

## 3. Technical solution

The architecture uses a small structured state that is updated directly from incoming observations and then mapped to an action/estimate:

```text
sensor/input
    |
normalization
    |
compact resolutive state
    |
relation / attractor / threshold evaluation
    |
output
    |
bounded online update
```

The inference core is intentionally independent of a mandatory neural-network runtime. Neural components may be added upstream or downstream in hybrid deployments, but they are not a required part of the core mechanism.

## 4. Disclosed technical features

1. Low-parameter edge inference core.
2. Deterministic/bounded online updates from streaming observations.
3. Separation between state representation, decision rule, and adaptation rule.
4. Compatibility with continuous sensor-control loops.
5. Ability to run without an LLM or deep neural network in the core loop.
6. Benchmarkable comparison against statistical and learned baselines.
7. Intended coupling with Resolutive Memory for persistent online experience.

## 5. Minimal normative model

Let `s_t` be the compact state, `x_t` the observation, `u_t` the inferred output, and `theta` compact parameters.

```text
s_t = UPDATE_STATE(s_{t-1}, x_t, theta)
u_t = DECIDE(s_t, theta)
theta_{t+1} = ADAPT(theta_t, s_t, x_t, u_t, feedback)
```

The implementation must constrain `ADAPT` so that online updates remain bounded and reproducible under identical input/order/seed conditions.

## 6. Worked example

An ESP32 measures a voltage input and controls an output signal. The resolutive inference state tracks the local response to previous control changes and selects the next adjustment intended to keep the measured voltage near a desired optimum. The controller updates from observations online instead of requiring a cloud model retraining cycle.

This example illustrates the architectural target; it does not establish closed-loop stability for arbitrary plants.

## 7. Reproducibility and evidence

The public `resolutive-inference` project includes a Compact-Pro development line and comparative baselines such as HMM/Student-t experiments. Development records report a compact configuration on the order of roughly one hundred parameters in one experimental variant.

These are development observations. VALIDATED status requires exact pinned commits, datasets/control plants, seeds, metrics, hardware, latency, memory, energy measurements, and statistical comparisons.

## 9. Failure modes and limitations

- Online adaptation can become unstable if update bounds are poorly chosen.
- Compact states can underfit complex tasks.
- Sensor drift/noise can move the system outside calibrated regions.
- A low parameter count does not automatically imply lower energy on every hardware platform.
- Robotics/control use requires separate stability and safety analysis.
- Hybrid neural components can reintroduce compute cost outside the core.

## 10. Related work and prior art

Relevant classes include adaptive control, online learning, finite-state estimators, HMMs, Kalman-style filtering, prototype methods, reservoir systems, lightweight neural inference, and reinforcement-learning controllers. The disclosed distinction is the compact resolutive-state inference/update architecture and its integration path with the broader Resolutive Memory family.

A formal literature and patent survey remains required.
