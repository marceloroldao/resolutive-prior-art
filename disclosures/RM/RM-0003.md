# RM-0003 — Persistent Concept Identity and Deterministic Concept-Relation Resolution

**Identifier:** RM-0003  
**Status:** EXPERIMENTAL  
**Version:** 0.1  
**Disclosure date:** 2026-09-05  
**Author:** Marcelo Roldão Matos

## Purpose

This disclosure records a post-v1 Memoria.ia mechanism in which durable concept identities, aliases, contextual senses and relation paths are persisted independently of transient language-model context and can be materialized into a native deterministic resolution path.

## Mechanism

The system separates at least four concerns:

1. authoritative concept identity and relation state;
2. durable persistence of that state;
3. native materialization into an execution index;
4. bounded deterministic resolution after ordinary memory resolution misses.

A concept is not identified only by the surface text used by a user. Multiple aliases may converge to a stable concept identity, while ambiguous forms fail closed unless sufficient contextual evidence selects a valid sense.

Concept relations can be traversed over bounded paths with provenance retained for audit. Native and Python paths are required to maintain behavioral parity before native activation.

## Resolution order

Concept resolution is intentionally not the first universal resolver. A representative policy is:

```text
ordinary memory resolution
    -> HIT: return
    -> MISS: explicit concept/alias resolution
             -> bounded relation path resolution
             -> HIT or UNRESOLVED
```

Ambiguous or unsupported interpretation returns `UNRESOLVED`; the resolver does not invent a concept merge.

## Persistence and native materialization

The authoritative concept catalog may be exported in deterministic form and materialized into Resolutive-DB as a derived native execution index. The authoritative semantic record remains distinct from the derived index.

The lifecycle includes:

```text
authoritative concept state
 -> deterministic catalog export
 -> stable fingerprint
 -> native/BDR materialization
 -> restart-safe reload
 -> native resolver activation
```

This allows persisted concept knowledge to survive process/device lifecycle boundaries and become directly usable by native resolution code.

## Scope and limitations

This disclosure does not claim invention of symbolic identifiers, aliases, graph traversal, databases, hash indexes or contextual disambiguation as isolated primitives. The disclosed mechanism concerns their specific organization as persistent concept identity feeding a restart-safe native resolutive execution path with fail-closed ambiguity and explicit HIT/UNRESOLVED semantics.

No claim is made that arbitrary natural language understanding is deterministic or constant-time.
