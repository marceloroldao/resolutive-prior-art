## 1. Release purpose

This release is intended to create an immutable, citable archival snapshot of the public technical disclosures that define the Resolutive Technology family as of v0.1.0.

The release is a defensive technical publication registry. It records mechanisms, architectures, assumptions, evidence status, implementation references, limitations, and historical relationships. It is not a patent filing, a declaration of patentability, a scientific validation certificate, or a claim that every experimental mechanism is production-ready.

## 2. Core computing foundation

The following disclosures form the principal architectural chain of the v0.1.0 publication:

1. `RF-0001` — Resolutive Technology Family: Foundational Architecture
2. `RM-0001` — Resolutive Memory Core
3. `RM-0002` — Trajectory Addressing and Retrieval
4. `MA2A-0001` — Memoria.ia Agent-to-Agent Protocol Architecture (L1/L2/L3)
5. `MA2A-0002` — Deterministic State Synchronization

Together these disclose the family-level organization of deterministic state/trajectory addressing, known-route reuse, local-first operation, optional external/neural resolution, compact state synchronization, privacy boundaries, deterministic conflict handling, and organizational trust/admission.

## 4. Critical claim boundaries frozen by this release

The v0.1.0 registry adopts the following explicit boundaries:

- O(1) terminology applies only to operations for which the stated data structure and lookup assumptions justify it, such as indexed lookup of a known resolutive address. It does not mean arbitrary intelligence, semantic interpretation, network synchronization, or universal computation is O(1).
- A cryptographic hash or integrity digest is a verifier and is not treated as a reversible source encoding by itself.
- Trajectory representation does not automatically imply practical or information-theoretic compression.
- Neural networks and LLMs may be used as optional resolvers or edge interfaces, but they are not required as the internal transport representation of the disclosed resolutive synchronization architecture.
- MA2A "zero token transport overhead" means that deterministic protocol synchronization need not transport LLM token strings; it does not mean zero network bytes or zero computational cost.
- Resolutive Physics hypotheses are recorded separately and are not prerequisites for the computing mechanisms to be implemented or tested.
- EXPERIMENTAL status means a concrete mechanism is disclosed but independent validation and/or fully pinned reproducibility may remain incomplete.

## 9. Zenodo-facing description

Version 0.1.0 of the Resolutive Prior Art Registry is a defensive technical publication snapshot for the Resolutive Technology family. The core publication chain discloses a shared architecture based on deterministic state and trajectory addressing, reuse of known resolution routes, local-first memory, optional external or neural resolution, and deterministic synchronization between compatible agents. It includes the Resolutive Family foundation (RF-0001), Resolutive Memory disclosures (RM-0001 and RM-0002), and the MA2A protocol architecture, synchronization, and organizational PKI disclosures (MA2A-0001 through MA2A-0003). Additional experimental disclosures for TRIVAX, Resolutive Inference, Resolutive Computing, reversible trajectory systems, hierarchical bit-relation analysis, and Resolutive Physics are included with separate evidence status and limitations. Complexity, compression, security, and scientific claims are deliberately scoped to the evidence stated in each disclosure.
